# Personal Portfolio

Hello, I'm a Computer Science student, and this is my personal portfolio built with React.js, Vite, and TypeScript. This project showcases my skills, projects, and experiences in a modern, responsive web format.

## About

This portfolio was created as a hands-on project to explore modern web development technologies and to present my work in a clean, efficient, and user-friendly interface. By building it with React, Vite, and TypeScript, I have focused on performance, maintainability, and type safety.

## Features

- **Responsive Design:** Ensures optimal viewing across various devices.
- **Modern UI/UX:** Clean, minimalistic design to highlight my projects.
- **Dynamic Content:** Interactive components powered by React.
- **Fast Development & Performance:** Leveraging Vite for rapid development and efficient bundling.
- **Type Safety:** TypeScript integration to enhance code quality and maintainability.

## Built With

- [React.js](https://reactjs.org/) – A library for building interactive user interfaces.
- [Vite](https://vitejs.dev/) – A fast build tool and development server.
- [TypeScript](https://www.typescriptlang.org/) – A strongly typed programming language that builds on JavaScript.
